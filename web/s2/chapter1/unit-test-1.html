Core Concepts

Summative check for Chapter 1 (second semester).

Test Structure

Typically: calculation fluency, fill-ins (units, brackets), area on grids / combined figures, and applications.

High-Frequency Focus

  • Parentheses change the order — work inside ( ) first.
  • $100\ ext{cm}^2 = 1\ ext{dm}^2$.
  • Split L-shapes; add rectangle areas.
