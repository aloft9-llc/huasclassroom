Learning Objectives

Students will be able to:

  1. 01Calculate expressions with parentheses using the correct order. (Question 1)
  2. 02Compare expressions with and without brackets. (Question 2)
  3. 03Write number sentences with brackets to match a story. (Question 3)
  4. 04Solve multi-step problems that need grouping. (Question 4–5)

Core Concepts

Parentheses group operations — calculate inside brackets first.

Brackets First

Step 1
Work inside parentheses ( ) first.
Step 2
Then × and ÷ (left to right).
Step 3
Then + and − (left to right).
ExpressionThinkValue
$(12 + 8) imes 3$$20 imes 3$$60$
$12 + 8 imes 3$$12 + 24$$36$
$(30 - 6) \div 4$$24 \div 4$$6$

With / Without Brackets

Same numbers, different grouping → different answers. Brackets show which part to do first.

Common error: ignoring brackets and doing × before + everywhere without checking for ( ).

Stories with Grouping

When a story has two steps that must stay together, write brackets in the number sentence.
