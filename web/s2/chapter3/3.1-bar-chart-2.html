Lesson Alignment

How this Shanghai Maths lesson connects to learning goals, Common Core, and Eureka Math.

Learning Objectives

Students will be able to:

  1. 01Draw a bar chart from a data table, including title, axes, and a sensible scale. (Question 1)
  2. 02Read values from a bar chart and name the greatest / least category. (Question 2, 4)
  3. 03Interpret what one grid square represents on the vertical scale. (Question 3)
  4. 04Calculate totals and differences from bar heights (including combining two related categories). (Question 4)

Core Concepts

How to build, scale, and read a bar chart — the teaching focus of pages 71–73.

Parts of a Bar Chart

Use this checklist every time students draw or read a chart.

PartWhat to includeExample from Q1
TitleWhat the chart is about“Results of shuttlecock kicking”
Vertical axisQuantity + unit + scale numbers“No. of kicks” with marks 0, 10, 20…
Horizontal axisCategories (names / groups)XD, XP, XQ, XY, XH
BarsEqual width; height = valueXQ tallest for kicks (49)

How to Draw (Question 1)

From a table → bar chart:

  1. Write a clear title.
  2. Label both axes (include units).
  3. Choose a scale so the tallest bar fits the grid.
  4. Draw bars of equal width; height matches each value.
  5. Label each category under its bar.

Choosing a Scale (Question 1 & 3)

Rule: Look at the largest value. Pick a friendly step (1, 2, 5, 10, 20, 25, 50, 100…) so the tallest bar fits.

Data setLargest valueSensible scale
Shuttlecock kicks$49$$1$ grid $= 10$ kicks
Rope skips$150$$1$ grid $= 25$ skips
River lengths (Q2)about $6300$ km$1000$ km marks on the axis
Tonnes bar (Q3)$40$$1$ grid $= 5$ tonnes
Question 3 trap: If the axis marks $0, 10, 20, \ldots$ but there are two grid squares between marks, then $1$ grid $= 5$ tonnes, not $10$. Count grids carefully: $8$ grids $\times 5 = 40$.

Reading a Bar Chart (Question 2)

River chart — lengths of Heilongjiang, Yellow, Yangtze, Zhujiang:

  • Find the tallest bar → longest river (Yangtze).
  • Read the height against the scale → about $6300$ kilometres.
When a bar sits between grid lines, estimate (e.g. a little above $6000$).

Compare & Calculate (Question 4 — Enhancement)

Class 3(1) PE activities (everyone does one activity only):

ActivityPupils
Long rope skipping$10$
Shuttlecock kicking$12$
Short rope skipping$6$
Badminton$2$
  • Most / least: Shuttlecock kicking (12); Badminton (2).
  • Total: $10 + 12 + 6 + 2 = 30$ pupils.
  • Difference trap: “Rope skipping” means long + short $= 10 + 6 = 16$. Difference from shuttlecock: $16 - 12 = 4$ (not $10 - 12$).
Combine categories when the question says “rope skipping” and the chart splits long / short.

Key Terms & Definitions (Reference)

TermDefinition
Bar chart / bar graphA chart that uses bars to show amounts for different categories.
CategoryA group named on the horizontal axis (e.g. a child’s name or an activity).
ScaleWhat each unit (or grid) on the vertical axis stands for.
AxisA reference line: vertical (quantity) or horizontal (categories).
TitleA short name that tells what the chart shows.
How many more / lessThe difference between two bar heights (subtract).

Key Answers

Quick reference for this lesson’s exercise answers.

1. Draw bar charts

  • Shuttlecock kicks — title e.g. “Results of shuttlecock kicking”; axis “No. of kicks”; scale e.g. 1 grid = 10. Bars: Dingding 40, Pang 24, Qiao 49, Ya 46, Hong 35.
  • Rope skipping — title e.g. “Results of rope skipping”; axis “No. of skips”; scale e.g. 1 grid = 20 or 25. Bars: 95, 50, 118, 150, 76.

2. Rivers

Yangtze is the longest; about $6300$ kilometres.

3. Scale

$1$ grid $= 5$ tonnes; the bar represents $40$ tonnes.

4. PE activities

  1. Most: shuttlecock kicking; least: badminton.
  2. Total $10+12+6+2=30$ pupils.
  3. Rope skipping (long + short) $10+6=16$; difference $16-12=4$.
