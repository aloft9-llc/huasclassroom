Lesson Alignment

How this unit test connects to learning goals, Common Core, and Eureka Math.

Learning Objectives

Students will be able to (across the test):

  1. 01Compute mental and column ×÷ with order of operations and remainders.
  2. 02Write number sentences from language (dividend / quotient / remainder).
  3. 03Find area of a composite shape by splitting into rectangles.
  4. 04Read and complete bar charts (Olympic medals; weekly violations).
  5. 05Solve multi-step application problems (packing, distance, rate).

Statistics Focus

Olympic gold medals chart: compare USA and Japan (“times as many”); identify who ranks first (China).

Drunk-driving weekly chart:

  • Each small grid represents a stated number of violations (OCR: about $20$).
  • Complete Saturday’s bar when the value is given (e.g. $470$).
  • Find fewest / most days; difference; weekly total; write a short observation.
For “complete the chart,” count grids from the scale first, then draw the missing bar to the correct height.

High-Frequency Focus

  • Remainder must be less than the divisor (MCQ: dividing by $25$ → greatest remainder $24$).
  • Packing: maximum groups + leftover pieces / boxes.
  • Ship: distance $= $ speed $\times$ time $+$ remaining distance to Port B.
  • Bar chart: read scale before comparing heights.

Key Answers

Quick reference for this lesson’s exercise answers.

1. Mental calculation

  • $8\times3\div6=4$;\; $(18+18)\div2=18$;\; $11+15\div3=16$;\; $15\div(5\times3)=1$
  • $6\times5\times4=120$;\; $22-(12+10)=0$;\; $48\div8\times8=48$;\; $99\times(99-99)=0$

2. Column method

  • $98\times42=4116$;\; $24\times302=7248$;\; $1320\div60=22$
  • $452\div56=8\,\mathrm{R}\,4$;\; $7832\div72=108\,\mathrm{R}\,56$

3. Step by step

  • $786-278-222=286$;\; $75\times55\div11=375$;\; $555\times20\div5=2220$
  • $(438-362)\div19=4$;\; $25\times16+25\times13+25=750$;\; $(379-193)\times15=2790$

4–5

  • Number: $(330-7)\div19=17$.
  • Composite area: $33\,\mathrm{m}^{2}$.

6. Fill in

  1. Height: cm; dictionary: cm; bicycle: km/h.
  2. Speed $56\,\mathrm{km/h}$. Table: $392$; $336$; $504$; $13$ hours.
  3. $450\,\mathrm{cm}=45\,\mathrm{dm}$;\; $30\,\mathrm{m}^{2}=3000\,\mathrm{dm}^{2}$;\; $2\,\mathrm{dm}^{2}\,4\,\mathrm{cm}^{2}=204\,\mathrm{cm}^{2}$.
  4. USA is $4$ times Japan; China ranks first; China has $28$ more golds than Russia.
  5. $4068\div46$: quotient is a two-digit number; highest place is tens.
  6. Greatest leading digit for 2-digit quotient: $6$; least for 3-digit: $7$.
  7. $1250$.
  8. Xiao Nan skipped faster.
  9. $2999\,\mathrm{g}<3\,\mathrm{kg}$;\; $500\,\mathrm{m}>5000\,\mathrm{cm}$.

7. Multiple choice

(1) C $24$;\; (2) C Xiao Ya;\; (3) B $120$.

8. Application

  1. $216\div30=7\,\mathrm{R}\,6$ → $7$ notepads, $6$ pieces left.
  2. $6960\div8=870$ boxes used; $30$ boxes left; $0$ parts left.
  3. $28\times12+120=456\,\mathrm{km}$.

9. Statistics

  1. $1$ grid $=20$ violations; Saturday bar $=470$.
  2. Fewest: Mon; $104$ fewer than Wed (largest); total $3349$.
  3. Open comment (e.g. Wed highest / Mon lowest; weekend still high).
