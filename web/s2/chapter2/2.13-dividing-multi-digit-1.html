Learning Objectives

Students will be able to:

  1. 01Divide multi-digit by two-digit using column method. (Question 1)
  2. 02Estimate using compatible numbers ($38\times50$). (Question 2)
  3. 03Solve minimum boats / rafts (round up). (Question 3)

Extend to $204 \div 12$, $2128 \div 38$; minimum rafts needed.

Minimum Rafts

Rooms × people ÷ capacity per raft → round up for leftover people.

Key Answers

Quick reference for this lesson’s exercise answers.

1. Fill in / let’s try

  • $204\div12=17$;\; $2128\div38=56$
  • $500\div20=25$;\; $500\div30=16\cdots20$;\; $500\div40=12\cdots20$

2. Column method

  • $999\div13=76\cdots11$;\; $999\div23=43\cdots10$;\; $999\div33=30\cdots9$
  • $999\div43=23\cdots10$;\; $999\div53=18\cdots45$;\; $999\div83=12\cdots3$

3. Patterns $\square35\div35$

  • $135\div35=3\cdots30$ … $935\div35=26\cdots25$
  • Hundreds $1$–$3$: $1$-digit quotient; $4$–$9$: $2$-digit quotient

4. Fill in brackets

  1. $2$-digit; tens place
  2. $1$-digit; digit $7$
  3. Smallest fill $3$
  4. Greatest fill $3$

5. Application

  1. $1400$ pine cones; $7$ more cans
  2. $64\,\text{min}$ round trip

6. Enhancement

  • $516\div26=19\cdots22$;\; $990\div38=26\cdots2$
