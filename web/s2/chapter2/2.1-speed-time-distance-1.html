Learning Objectives

Students will be able to:

  1. 01Understand speed as distance travelled per unit of time. (Question 1)
  2. 02Fill in distance, time, or speed in tables. (Question 1–2)
  3. 03Compare who is faster from distance and time data. (Question 3)

Core Concepts

Introduce speed as distance per unit time; use $D = S \times T$.

Speed Formula

Distance = speed × time  ·  Speed = distance ÷ time  ·  Time = distance ÷ speed

Keep units consistent (m/min, km/h, …).

Fill Tables

Given two of distance, time, speed — find the third.

Compare Speeds

Convert to the same units before comparing who is faster.

Key Answers

Quick reference for this lesson’s exercise answers.

1. Fill in the table

  • Walking: speed $14\,\text{km/h}$ (given time $3\,\text{h}$, distance $42\,\text{km}$)
  • Bus: speed $900\,\text{m/min}$ (given time $5\,\text{min}$, distance $4500\,\text{m}$)
  • Motorbike: speed $5\,\text{m/s}$ (given time $80\,\text{s}$, distance $400\,\text{m}$)

2. Suitable units

  • Pigeon: $\text{km/h}$; lion: $\text{km/min}$; elephant: $\text{m/min}$; puppy: $\text{m/min}$

3. Multiple choice

  1. C (speed)
  2. B — truck $70\,\text{km/h}$, car $90\,\text{km/h}$; car faster
  3. C — rates $103$, $86$, $120$ miles/day; Team C fastest

4. Fill in the brackets

  1. Read as $508$ metres per minute; means travelling $508\,\text{m}$ in $1\,\text{min}$
  2. Written $27\,\text{km/h}$; means travelling $27\,\text{km}$ in $1\,\text{h}$
  3. $6\,\text{m/s}$; $40\,\text{m/min}$; $16\,\text{km/h}$

5. Whose speed was fastest?

  • Xiao Ya: $100\,\text{m/min}$; Xiao Qiao: $120\,\text{m/min}$; Xiao Dingding: $125\,\text{m/min}$; Xiao Pang: $130\,\text{m/min}$
  • Fastest: Xiao Pang

6. Application

  1. $80\,\text{m/min}$
  2. $72\,\text{m/min}$
