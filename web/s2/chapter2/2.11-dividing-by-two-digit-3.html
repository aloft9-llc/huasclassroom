Core Concepts

When first digits match, use smaller trial quotient (e.g. 220÷30).

Trial Quotient

Both have same first digit → try a smaller quotient first.

Adjust Down

$220 \div 30$: try 5, not 7 — $30 \times 7$ too big.

Area Problems

Area ÷ length = width; compare width and length.

Key Answers

Quick reference for this lesson’s exercise answers.

1. Let’s try

  1. $89\div28=3\cdots5$
  2. $80\div28=2\cdots24$
  3. $421\div57=7\cdots22$
  4. $134\div19=7\cdots1$
  5. $222\div28=7\cdots26$
  6. $738\div78=9\cdots36$

2. Column method

  • $88\div22=4$;\; $72\div36=2$;\; $38\div19=2$
  • $188\div22=8\cdots12$;\; $272\div36=7\cdots20$;\; $138\div19=7\cdots5$

3. Number sentences

  1. $656\div82=8$
  2. $413\div59=7$

4. Application

  1. $21\,\text{m}$ shorter
  2. $870$;\; $6$ times; remainder $90$
  3. $3$ weeks $4$ days
