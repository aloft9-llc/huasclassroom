How this Shanghai Maths lesson connects to learning goals, Common Core, and Eureka Math.

Learning Objectives

Students will be able to:

  1. 01Convert between km/h and m/min when needed. (Question 1–2)
  2. 02Solve two-route or two-person distance problems. (Question 3–4)
  3. 03Apply real-world speed contexts (metro, travel). (Question 5)

Core Concepts

Apply $D=S\times T$ with km/h and m/min; multi-step route problems.

Unit Conversion

$1\ \text{km/h} = 1000\ \text{m} \div 3600\ \text{s}$ — at Grade 3, use friendly conversions given in the text.

Two Routes

Mum drives; child cycles — different speeds, same arrival time → find each distance.

Applications

Metro line length ÷ speed → journey time.

Key Answers

Quick reference for this lesson’s exercise answers.

1. Let’s compare

  1. Xiao Dingding faster; less time $\Rightarrow$ faster speed
  2. Xiao Qiao faster; longer distance $\Rightarrow$ faster speed

2. Fill in the table

  • Speed $84\,\text{m/min}$; time $17\,\text{h}$; distance $944\,\text{m}$

3. Compare with $>$, $<$, $=$

  1. Distance A $>$ distance B
  2. Time A $>$ time B
  3. Speed A $<$ speed B

4. Application

  1. Mum: $21000\,\text{m}$; Xiao Qiang: $8\,\text{km}$
  2. $360\,\text{km}$
  3. $1500\,\text{m}$
  4. $12\,\text{km/min}$; $2880\,\text{km}$
  5. $30\,\text{min}$

5–6. Enhancement

  1. Xiao Lan fastest ($6.25\,\text{m/s}$)
  2. M walked $500\,\text{m}$; $10\,\text{min}$ so far; $AB=650\,\text{m}$
