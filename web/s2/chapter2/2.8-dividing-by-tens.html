Core Concepts

Divide by whole tens: $96 \div 60$, $572 \div 80$ with remainder.

Divide by Tens

Think: how many tens fit? $96 \div 60 = 1\ \text{R}\ 36$.

Column ÷

Standard layout: quotient, multiply back, subtract, bring down.

Key Answers

Quick reference for this lesson’s exercise answers.

1. Greatest number in ( )

  • $50\times(3)<157$;\; $70\times(5)<369$;\; $80\times(6)<508$
  • $(7)\times30<231$;\; $(9)\times40<369$;\; $(4)\times90<396$

2. Think carefully

  1. $92\div40=2\cdots12$
  2. $362\div40=9\cdots2$
  3. $75\div20=3\cdots15$
  4. $256\div30=8\cdots16$

3. Column method

  • $96\div60=1\cdots36$;\; $145\div20=7\cdots5$;\; $572\div80=7\cdots12$
  • $360\div70=5\cdots10$;\; $455\div50=9\cdots5$;\; $666\div90=7\cdots36$

4. Number sentences

  1. $16$ (since $961=16\times60+1$)
  2. Difference $304$

5. Application

  1. $5$ per group, $17$ left
  2. Rows $10,20,30,40,60$ $\rightarrow$ $72,36,24,18,12$ per row

6. Enhancement

  1. $80$
  2. 1st Xiao Qiang; 3rd Xiao Xin
  3. Dividend $66$
  4. $5\,\text{m}$
