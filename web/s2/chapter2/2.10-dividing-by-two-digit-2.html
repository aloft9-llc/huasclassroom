Core Concepts

More two-digit division; packing pupils into boats.

Column Fluency

Round Up

182 pupils, 12 per boat → quotient + 1 if remainder ≠ 0.

Check Division

$divisor \times quotient + remainder = dividend$.

Key Answers

Quick reference for this lesson’s exercise answers.

1. Let’s try (adjust quotient)

  1. $480\div63=7\cdots39$
  2. $369\div93=3\cdots90$
  3. $334\div43=7\cdots33$

2. Column method

  • $500\div89=5\cdots55$;\; $321\div56=5\cdots41$;\; $317\div66=4\cdots53$
  • $84\div22=3\cdots18$;\; $178\div22=8\cdots2$;\; $453\div57=7\cdots54$

3. Greatest in ( )

  • $30\times(6)<207$;\; $60\times(6)<415$;\; $40\times(7)<316$
  • $70\times(8)<566$;\; $50\times(8)<410$;\; $80\times(9)<768$

4. Number sentences

  1. $192\div32=6$
  2. $344\div43=8$

5. Application

  2. $18$ boats
  3. $11$ more days
