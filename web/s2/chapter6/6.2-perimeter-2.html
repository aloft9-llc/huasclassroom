Core Concepts

Measure sides; same wire → same perimeter for different shapes.

Measure Sides

Measure each side, then add all sides.

Same Wire

A fixed-length closed wire always has the same perimeter, even if the shape changes.

Multi-Square Blocks

Joining squares changes perimeter — overlapping sides are not part of the outer edge.

Key Answers

Quick reference for this lesson’s exercise answers.

Key answers

  1. Measure (unit mm): measure each side with a ruler, then add. (Depends on print size.)
  2. Grid (1 dm): 20 dm; 18 dm; 22 dm; 22 dm.
  3. MCQ: (1) A; (2) B.
  4. Shapes M & N: same perimeter.
  5. Ant: shortest $7\times8=56$ cm.
  6. Pentominoes: 11 more combinations; shortest perimeter 10 cm.
