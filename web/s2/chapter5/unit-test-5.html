Quick reference for this lesson’s exercise answers.

1. Mental

  • $(6+12)\times4=72$;\; $72-72\div6=60$;\; $38+11\times2=60$;\; $74-44+18=48$

2. Column + calculator

$281\times46=12\,926$;\; $8732\div12=727\,\mathrm{R}\,8$;\; $305\times48=14\,640$;\; $5616\div78=72$.

  • $7200\div24\times105=31\,500$;\; $(18539-829)\div35=506$

  1. Average speed $2400\div120=20\,\mathrm{km/h}$.
  2. $(2000-785)\div3=405$ sets.
  3. $8010\div30-1980\div30=201$ more bins/day.

$(98+92+88+77+100)\div5=91$.
