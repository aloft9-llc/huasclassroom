Core Concepts

Use a calculator for multi-step ×÷; spot patterns like ×101.

Multi-Step Calc

Work left to right unless brackets group a step.

Key Order

For $2160 \div 20 - 57$: enter 2160, ÷, 20, =, then −, 57, =.

Number Patterns

$n \times 101$ patterns — check with a calculator, then write more examples.

Key Answers

Quick reference for this lesson’s exercise answers.

1–2. Key order / check

  • $58209+4293=62502$ (keys $5\,8\,2\,0\,9\,+\,4\,2\,9\,3\,=$).
  • Check: $69\times34+1=2347$ — the division is correct.

3. Column / step + calculator

$7079\times830=5\,875\,570$;\; $623\times741=461\,643$;\; $3802+19578=23\,380$.

4–5

  • $2160\div20-57=51$.
  • Total spend $2398+396+180=2974$ yuan; public rental total $82\,240$ units.

6. Pattern ×101

  • $86\times101=8686$, etc.; two-digit $ab\times101$ “repeats” the digits.
  • $860\times101=86860$;\; $453\times101=45753$, etc. (append / carry pattern).
  • Examples: $99\times101=9999$;\; $20\times101=2020$;\; $354\times101=35754$;\; $416\times101=42016$.

7. Fastest route

Speeds (km/min): Route 1 $\approx0.45667$; Route 2 $0.56875$; Route 3 $\approx0.50882$. Route 2 is fastest.
