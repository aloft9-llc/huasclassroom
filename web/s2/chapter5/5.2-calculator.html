Lesson Alignment

How this Shanghai Maths lesson connects to learning goals, Common Core, and Eureka Math.

Learning Objectives

Students will be able to:

  1. 01Match calculator keys to names. (Question 1)
  2. 02Enter keystroke sequences for +, −, ×. (Question 2)
  3. 03Form 2-digit × 2-digit with given digits (max/min product). (Question 3)

Core Concepts

Match calculator keys; enter multi-step calculations correctly.

Calculator Keys

Power/All Clear, CE (clear entry), +, −, ×, ÷, =.

Keystroke Order

Enter numbers and operations in the same order as the number sentence.

Digit Challenges

Arrange four digits into two 2-digit factors for largest/smallest product.

Key Answers

Quick reference for this lesson’s exercise answers.

1. Match keys

Power/all clear ↔ on/c;\; M+ ↔ memory add;\; M− ↔ memory subtract;\; MR ↔ memory recall;\; CE ↔ clear entry;\; MC ↔ memory clear.

2. Multiple choice

(1) B turn off automatically;\; (2) D CE (clear the wrong entry);\; (3) B $3$ (display $312$).

3. Calculator

$1364$;\; $89168$;\; $1568$;\; $1338$.

4. Column + check

$763+337=1100$;\; $5000-697=4303$;\; $8457\times103=871\,071$;\; $1440\div120=12$;\; $9640\div48=200\,\mathrm{R}\,40$.

5. Largest / smallest products

  • Digits $4,9,7,2$: largest $92\times74=6808$; smallest $27\times49=1323$.
  • Digits $5,6,7,8$: largest $76\times85=6460$; smallest $57\times68=3876$.
