1.5 · Figures made up of squares — multi-square blocks

Open lesson notes →

1. Fill in the brackets

  1. two-square block
  2. three-square block
  3. $4$ unit squares

2. Draw on the grids

  1. Add one square to each two-square block to make a three-square block (any attached edge-to-edge position is acceptable).
  2. Add one square to each three-square block to make a four-square block (sample: T / L / straight tetrominoes).
  3. Sample for $4\times3$: three $2\times2$ blocks. Sample for $4\times4$: four $2\times2$ blocks.
  4. Sample for $3\times5$: three horizontal $1\times5$ strips, or five vertical $3\times1$ strips (other valid tilings OK).

3. Enhancement — tile using each block once

  1. Fill the $4\times4$ target using four of the given four-square blocks (area $16$).
  2. Fill the $5\times5$ target (area $25$) using a selection of the given blocks whose areas sum to $25$ (sample graded solution used L, U, $2\times2$, T, L, and a $1\times3$).
