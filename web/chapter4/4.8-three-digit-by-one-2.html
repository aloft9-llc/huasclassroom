Lesson Alignment

How this Shanghai Maths lesson connects to learning goals, Common Core, and Eureka Math.

Learning Objectives

Students will be able to:

  1. 01Choose digits so the quotient has 2 or 3 digits.
  2. 02Practice three-digit ÷ one-digit fluency.
  3. 03Classify numbers into groups (enhancement sorting).

Core Concepts

Focus on quotient size and flexible reasoning with three-digit dividends.

Controlling Quotient Digits

In $128 \div 3$, greatest/least digit in a box to make a 2-digit or 3-digit quotient.

Number Classification

Sort numbers such as 345, 934, 616, 299 into given groups.

Enhancement

Think carefully which property defines each group.

Key Answers

Quick reference for this lesson’s exercise answers.

1. Mental calculation

  • $80\div4=20$,\; $600\div6=100$,\; $510-480=30$
  • $39\div3=13$,\; $900\div3=300$,\; $97\div7=13\ldots6$
  • $23\times4=92$,\; $25\times6=150$,\; $24\times5=120$

2. Try it

$189\div6=31\ldots3$

3. Digits of quotient then calculate

  • $624\div3=208$,\; $936\div8=117$,\; $423\div6=70\ldots3$,\; $5636\div4=1409$

4. Calculate and check

  • $656\div6=109\ldots2$;\; $736\div9=81\ldots7$;\; $496\div7=70\ldots6$

5. Fill in the brackets

  1. Greatest for $2$-digit quotient: $(2)$;\; least for $3$-digit: $(3)$
  2. $(8)$
  3. $(0)$
  4. Dividend $(96)$

6. Application problems

  1. $600$ mosquitoes per day
  2. $96$ per big box;\; $12$ per small box

7–9. Enhancement

  1. ÷2 rem $0$: $630$,\; $616$,\; $934$;\; ÷3 rem $1$: $373$,\; $934$,\; $616$;\; ÷7 rem $5$: $299$
  2. Xiao Pang faster (e.g. $76$/h vs $72$/h)
  3. $16$ kg in Bucket A at first
