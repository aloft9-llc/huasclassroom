Key Answers

Quick reference for this lesson’s exercise answers.

1. Related facts

  • $896\div7=128$;\; $806\times9=7254$;\; $8120\div4=2030$

2. Correct the mistakes

  • $354\div6=59$ correct;\; $663\div7=94\ldots5$;\; $428\div4=107$ correct

3. Column method

  • $380\div3=126\ldots2$,\; $843\div6=140\ldots3$,\; $709\div7=101\ldots2$
  • $450\div6=75$,\; $750\div5=150$,\; $919\div9=102\ldots1$

4. Find the number

  • $(38)\times7=266$;\; $9\times(54)=486$;\; $(2100)\div6=350$;\; $384\div(48)=8$

5. Fill in the brackets

  1. $(2025)$
  2. $(145)$ times
  3. $(1)$
  4. $(4)$ possible values

6. True or false

  1. $\surd$
  2. $\times$
  3. $\times$
  4. $\times$
