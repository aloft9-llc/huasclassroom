Core Concepts

Use place value: divide the non-zero part, then place zeros correctly.

Tens / Hundreds Pattern

$$80 \div 4 = 20,\quad 160 \div 4 = 40,\quad 200 \div 4 = 50$$
Think: $8 \div 4 = 2$ tens → $80 \div 4 = 20$.

Inverse of Multiplication

“50 times what number is 350?” → $350 \div 50 = 7$.

Applications

  • TV prices: $7500 \div 3$.
  • Books shared among grades/classes (two-step).

Key Answers

Quick reference for this lesson’s exercise answers.

1. Let’s calculate

  • $8\div4=2$,\; $80\div4=20$;\; $16\div4=4$,\; $160\div4=40$;\; $32\div4=8$,\; $320\div4=80$;\; $20\div4=5$,\; $200\div4=50$
  • $9\div3=3$,\; $90\div3=30$,\; $900\div3=300$;\; $8\div2=4$,\; $80\div2=40$,\; $800\div2=400$;\; $5\div5=1$,\; $50\div5=10$,\; $500\div5=100$;\; $10\div5=2$,\; $100\div5=20$,\; $1000\div5=200$

2. Fill in the brackets

  • $(8)\times60=480$;\; $480\div60=(8)$;\; $480\div(8)=60$
  • $(8)\times70=560$;\; $560\div70=(8)$;\; $560\div(8)=70$
  • $80\times(9)=720$;\; $720\div80=(9)$;\; $720\div(9)=80$

3. Use your knowledge creatively

  • $400\div50=8$,\; $400\div8=50$;\; $210\div7=30$,\; $210\div30=7$;\; $540\div90=6$,\; $540\div6=90$;\; $40\div2=20$,\; $40\div20=2$;\; $300\div50=6$,\; $300\div6=50$
  • $120\div30=4$,\; $360\div60=6$;\; $250\div50=5$,\; $630\div90=7$;\; $150\div30=5$,\; $490\div70=7$;\; $810\div90=9$,\; $450\div90=5$;\; $3600\div40=90$,\; $1600\div20=80$

4. Multiple choice

  1. D (not sure)
  2. C (about $50$ kg)
  3. B (not enough; $28\times3=84<90$)

5. Write the number sentences and calculate

  1. $640\div8=80$
  2. $350\div50=7$

6. Application problems

  1. $7500\div3=2500$ yuan
  2. $240\times(4+1)=1200$ litres
  3. $650+250=900$;\; $900\div6=150$ books per grade;\; $150\div5=30$ books per class
  4. Small cup $20$ g;\; big cup $40$ g

7. Enhancement

$\triangle=3$,\; $\square=20$,\; $\bigcirc=9$
