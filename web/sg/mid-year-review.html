Core concepts

Test habits (Shanghai-aligned)

  1. Structure first. Place value? ±? ×÷? Money?
  2. Rewrite unit language as numerals before computing.
  3. Check with the inverse operation.
  4. For challenges: draw a model; name known / unknown.

Strand checklist

  • 4-digit place value & expanded form
  • Compare / order / patterns
  • Multi-digit ± with regrouping
  • Tables 2–10; remainders
  • Dollars & cents word problems
Diagnose weak strands, then return to the matching topic note and Shanghai lesson.
