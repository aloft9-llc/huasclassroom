## Lesson Alignment

### Learning Objectives

Students will be able to (across the test):

1. **Compute** mental and column +/−/×/÷ with order of operations.
2. **Write number sentences** from language and compare expressions.
3. **Reason** about place value, triangles, and multi-square blocks.
4. **Solve multi-step application problems**.

## Core Concepts

- ×÷ before +−; check borrowing across zeros (\(1002-888=114\)).
- Regroup: \(472-148-152=472-(148+152)\).
- Triangle type from greatest angle; multi-square area before tiling.
- Application patterns: remaining pages, half unfinished, “less than,” groups + backup.

## Key Terms

Column method, order of operations, number sentence, less than / more than, multi-square block, acute-angled triangle.
