## Lesson Alignment

### Learning Objectives

Students will be able to:

1. **Mix skills** from Topics 1–5 in timed or test-style items (PART 1 / PART 2).
2. **Move between** place value, ±, ×÷, patterns, and money without a topic cue.
3. **Explain** answers using Shanghai-style core language (sum, difference, quotient, place).
4. **Stretch** with More Challenging Problems that demand multi-step reasoning.

### Common Core Standards

Spans **3.NBT**, **3.OA**, and money (**2.MD.C.8**), matching Topics 1–5.

## Core Concepts

### Test habits (Shanghai-aligned)

1. Read once for structure (place value? ±? ×÷? money?).
2. Rewrite unit language as numerals before computing.
3. Check with the inverse operation.
4. For challenges: draw a model; name what is known / unknown.

### Sample strand checklist

- [ ] 4-digit place value & expanded form  
- [ ] Compare / order / patterns  
- [ ] Multi-digit ± with regrouping  
- [ ] Tables 2–10; remainders  
- [ ] Dollars & cents word problems
