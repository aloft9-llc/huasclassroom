## Core Concepts

How to build, scale, and read a bar chart — the teaching focus of pages 71–73.

### Parts of a Bar Chart

| Part | What to include | Example from Q1 |
|------|-----------------|-----------------|
| **Title** | What the chart is about | “Results of shuttlecock kicking” |
| **Vertical axis** | Quantity + unit + scale | “No. of kicks” |
| **Horizontal axis** | Categories | XD, XP, XQ, XY, XH |
| **Bars** | Equal width; height = value | XQ tallest for kicks (49) |

### How to Draw (Question 1)

1. Write a clear **title**.
2. Label both **axes** (include units).
3. Choose a **scale** so the tallest bar fits the grid.
4. Draw bars of **equal width**; height matches each value.
5. Label each category under its bar.

**Q1 data (kicks):** Dingding 40, Pang 24, Qiao 49, Ya 46, Hong 35.  
**Q1 data (skips):** 95, 50, 118, 150, 76 — needs a larger scale (e.g. 25 per grid).

### Choosing a Scale

**Rule:** Look at the **largest** value. Pick a friendly step (1, 2, 5, 10, 20, 25, 50, 100…) so the tallest bar fits.

| Data set | Largest | Sensible scale |
|----------|---------|----------------|
| Shuttlecock kicks | 49 | 1 grid = 10 kicks |
| Rope skips | 150 | 1 grid = 25 skips |
| River lengths (Q2) | ~6300 km | 1000 km marks |
| Tonnes bar (Q3) | 40 | 1 grid = 5 tonnes |

**Question 3 trap:** If axis marks are 0, 10, 20… but there are *two* grid squares between marks, then 1 grid = 5 tonnes. Count grids: \(8 \times 5 = 40\).

### Reading a Bar Chart (Question 2)

River chart (Heilongjiang, Yellow, Yangtze, Zhujiang):

- Tallest bar → longest river (**Yangtze**).
- Read height against scale → about **6300** kilometres.

### Compare & Calculate (Question 4)

Class 3(1) PE activities:

| Activity | Pupils |
|----------|--------|
| Long rope skipping | 10 |
| Shuttlecock kicking | 12 |
| Short rope skipping | 6 |
| Badminton | 2 |

- Most / least: Shuttlecock (12); Badminton (2).
- Total: \(10 + 12 + 6 + 2 = 30\).
- **Trap:** “Rope skipping” = long + short = 16. Difference from shuttlecock: \(16 - 12 = 4\).

## Key Terms

- **Bar chart / bar graph:** Uses bars to show amounts for categories.
- **Category:** A group on the horizontal axis.
- **Scale:** What each unit (or grid) on the vertical axis stands for.
- **Axis:** Vertical (quantity) or horizontal (categories).
- **How many more / less:** Difference between two bar heights.
