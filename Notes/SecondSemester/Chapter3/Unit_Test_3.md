## Lesson Alignment

### Learning Objectives

Students will be able to (across the test):

1. **Compute** mental and column ×÷ with order of operations and remainders.
2. **Write** number sentences from language (dividend / quotient / remainder).
3. **Find** area of a composite shape by splitting into rectangles.
4. **Read and complete** bar charts (Olympic medals; weekly violations).
5. **Solve** multi-step application problems (packing, distance, rate).

### Statistics Focus

- **Olympic chart:** compare USA vs Japan; China ranks first.
- **Weekly violations chart:** know grid value; complete Saturday; find fewest/most; weekly total; write an observation.

### High-Frequency Focus

- Greatest remainder when dividing by \(n\) is \(n - 1\).
- Packing → maximum groups + leftover.
- Ship: distance = speed × time + remaining distance.
- Always read the bar-chart scale first.
